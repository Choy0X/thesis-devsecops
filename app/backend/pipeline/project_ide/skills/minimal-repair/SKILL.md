Read the implementation and callers before editing. State the behavioral intent to preserve. Change only the active chat workspace. Do not modify the original source folder or installed dependencies. Keep the patch focused on the supported cause. Run the relevant regression checks with permitted tools and inspect actual results. A successful edit is not successful verification. Integration, package upgrades, commits, pushes, and pull requests require their separate explicit actions.
